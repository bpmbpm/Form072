## Граф 072 формы
Визуализация в виде графа Формы 0409072 обязательной отчетности Цетрального Банка  
Форма 0409072 — «Сведения о показателях операционной надёжности кредитной организации и применяемых ею информационных технологиях при осуществлении банковской деятельности и деятельности в сфере финансовых рынков»
- [«Архитектура в Графе». Графическая визуализация формата CSV/| формы «Операционной надежности и ИТ» (№ 0409072)](https://habr.com/ru/articles/981610/)
